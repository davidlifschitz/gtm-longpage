# LongPage

Drop a tall JPG of stacked pages. Get a multi-page PDF. Files never leave the browser.

Ask this answers: [How can I turn a long jpg into multiple page pdf?](https://www.reddit.com/r/pdf/comments/1vsbtzj/how_can_i_turn_a_long_jpg_into_multiple_page_pdf/)

- No account
- No upload
- Cap: 25 MB, 60 pages
- White gutters become cuts; or split evenly

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

A 200-page strip may need to be cropped into batches first.
